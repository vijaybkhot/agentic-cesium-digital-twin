# Agent-Assisted Cesium Digital Twin Research Prototype v0.1.0

`v0.1.0` is the initial open-source research-prototype release of the
Agent-Assisted Cesium Digital Twin repository.

## Highlights

- React and TypeScript application with a config-driven CesiumJS viewer.
- New-project/image-intake, controlled-facility, modular-housing,
  property-specific disaster-resilience, and urban-resilience modes.
- Local OSM/FEMA/USGS acquisition, processing, provenance, and validation
  workflows for selected urban-resilience research experiments.
- An isolated ArcGIS SceneView experiment consuming selected committed GeoJSON
  from the same upstream data pipeline.
- Typed interfaces and mock local implementations for future reconstruction and
  AI-agent integrations.
- Apache-2.0 licensing, third-party notices, contributor/security guidance, and
  automated GitHub Actions validation.

## Validation

The release is built from committed local datasets. The aggregate validation
checks the USGS elevation sample, urban-resilience properties and flood zones,
community/public-safety facilities, LA-1/FEMA relationships, fictional
disaster-resilience data, TypeScript compilation, and the Vite production
build. The final GitHub release description will link to the successful
validation run for the tagged commit.

## Important limitations

This software is a research prototype, not a production or emergency-management
system. It does not provide official FEMA determinations, live flood conditions,
road passability, facility availability, evacuation guidance, or safety advice.
OpenStreetMap coverage may be incomplete. Ground-elevation samples are not
building-floor elevations or flood depths. The reconstruction and AI-agent
backends remain mock local implementations or interface boundaries.

Optional Cesium ion and ArcGIS services require credentials supplied by each
user. No credential is included in the release.
